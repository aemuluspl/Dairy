# Hash

Школьный дневник и домашние задания. В этом репозитории — только готовые сборки приложения, без исходного кода.

## Скачать и установить

1. Открой [последний релиз](https://github.com/aemuluspl/Dairy/releases/latest).
2. Скачай файл `Hash-<версия>.apk` на телефон.
3. Открой файл — Android попросит разрешить установку из этого источника.
4. Разреши и нажми «Установить».

Требования: Android 7.0 и новее.

Всё хранится только на телефоне: задачи, расписание, настройки. Приложение ничего никуда не отправляет.
